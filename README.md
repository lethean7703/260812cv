# 강승희 CV · GitHub Pages

AI 활용 교육가 강승희의 개인 CV/포트폴리오 웹페이지입니다.

## GitHub Pages 배포

1. 이 폴더의 `index.html`과 `style.css`를 GitHub 저장소에 업로드합니다.
2. GitHub 저장소의 **Settings → Pages**로 이동합니다.
3. **Deploy from a branch**를 선택합니다.
4. Branch는 `main`, 폴더는 `/ (root)`로 선택합니다.
5. 저장하면 GitHub Pages 주소가 생성됩니다.

## 먼저 수정할 부분

`index.html`에서 다음 항목을 본인 정보로 변경하세요.

- 이메일
- GitHub 주소
- Instagram 주소
- 프로젝트명/경력/교육 이력
- 필요한 경우 프로필 사진 추가
